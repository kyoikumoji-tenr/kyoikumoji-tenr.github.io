# kyoikumoji-tenr.github.io

イベント公開用のサイト置き場です。
イベントごとにフォルダを分け、フォルダの中で作品番号を管理します。

公開URL: https://kyoikumoji-tenr.github.io/

## フォルダの命名ルール

- コンテスト系イベントは `mojicontest-` + 3桁の通し番号
  - `mojicontest-000` … テスト用（諱文字コンテストのテスト）
  - `mojicontest-001` … 本実装の1回目（以降 002, 003… と増やす）
- 「コンテスト」と呼ばない新しいイベントは、`contest` を含まない別名のフォルダにする

お題やイベント名をフォルダ名には付けません（再開催しても番号が混ざらないようにするため）。

## イベント一覧

- `mojicontest-000/` … 諱文字コンテスト（テスト）

## 共通ファイル

- `assets/fonts/GenZenGothicKai.ttf` … 全イベント共通のフォント（源全ゴシック改）。各イベントのページから参照する
