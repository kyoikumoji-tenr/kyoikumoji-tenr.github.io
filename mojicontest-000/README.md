# 諱文字コンテスト（テスト）

「描き人知らず」形式のイベント「諱文字コンテスト」の公開サイトです。
作品は作者名を伏せた状態で題字とセットで公開され、参加者同士で作者を予想します。
予想期間が終わった後、答え合わせとして各作品の作成者名を公開します。

公開URL: https://kyoikumoji-tenr.github.io/mojicontest-000/

## 構成

- `config.js` … メイン設定（企画名と今のウェーブ）。運用で触るのは基本ここだけ
- `index.html` … 入口。config のウェーブに合っている方へ自動で振り分ける
- `guess/` … 予想ウェーブ一式（`index.html` 本体＋ `data.js` ＋ `assets/`）
- `answer/` … 答え合わせウェーブ一式（`index.html` 本体＋ `data.js` ＋ `assets/`）

## 運用メモ

### ウェーブの切り替え

`config.js` の `wave` を書き換えます。

- `"guess"` … 予想ウェーブ
- `"answer"` … 答え合わせウェーブ

**重要**: `answer/data.js`（作成者名入り）は、答え合わせに切り替えるタイミングで
初めて配置してください。予想期間中に置くと、ファイルの場所を推測された時点で
作者が分かってしまいます。切り替えの手順は「① answer/data.js と answer/assets を
配置する → ② config.js の wave を "answer" に変える」の順です。

### 作品の追加

各ウェーブのフォルダ内で行います。

1. 作品ファイルを `assets/` に置く（例: `guess/assets/004.png`）
2. そのフォルダの `data.js` の `entries` に1行追加する

```
{ no: 4, title: "題字", type: "image", media: "assets/004.png" }
```

- `type` は `"image"`（画像）／`"video"`（動画）／`"gif"`
- 動画・gif は `thumb: "assets/004.jpg"` のようにサムネイル画像も指定できます
- `guess/data.js` には `author`（作成者名）を絶対に書かないでください

### 予想の保存について

参加者が入力した予想・メモは、各参加者のブラウザ内（localStorage）にだけ保存され、
サーバーには送信されません。保存キーはページの場所ごとに分かれているので、
イベントフォルダが違えば予想が混ざることはありません。
共有用PNG書き出しもブラウザ内で生成されます。

書き出し画像のレイアウトは、対象件数 N に対して
行数 = ⌊√N⌋、列数 = ⌈N ÷ 行数⌉ で自動計算されます（列数が10を超える場合のみ10列）。
作品が0件のときは書き出しボタンが無効になり、エラーにはなりません。
