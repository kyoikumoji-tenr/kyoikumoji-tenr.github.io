# 諱文字コンテスト

「描き人知らず」形式のイベント「諱文字コンテスト」の公開サイトです。
作品は作者名を伏せた状態で題字とセットで公開され、参加者同士で作者を予想します。
予想期間が終わった後、答え合わせとして各作品の作成者名を公開します。

公開URL: https://kyoikumoji-tenr.github.io/mojicontest-000/

## 構成

- `index.html` … サイト本体（予想パート／答え合わせパートの両対応）
- `data.js` … 作品データとフェーズ設定（運用はこのファイルだけ編集します）
- `assets/` … 作品画像・動画ファイル

## 運用メモ

### フェーズの切り替え

`data.js` の先頭にある `phase` を書き換えます。

- `"guess"` … 予想パート。作者名は表示されません。
- `"answer"` … 答え合わせパート。作成者名が表示されます。

**重要**: 予想パートで公開している間は、`data.js` の各作品に `author`（作成者名）を
書かないでください。書くとページのソースから作者が分かってしまいます。
答え合わせに切り替えるタイミングで、`author` を追加して `phase` を `"answer"` に変えます。

### 作品の追加

1. 作品ファイルを `assets/` に置く（例: `assets/004.png`）
2. `data.js` の `entries` に1行追加する

```
{ no: 4, title: "題字", type: "image", media: "assets/004.png" }
```

- `type` は `"image"`（画像）／`"video"`（動画）／`"gif"`
- 動画・gif は `thumb: "assets/004.jpg"` のようにサムネイル画像も指定できます

### 予想の保存について

参加者が入力した予想・メモは、各参加者のブラウザ内（localStorage）にだけ保存され、
サーバーには送信されません。共有用PNG書き出しもブラウザ内で生成されます。

書き出し画像のレイアウトは、対象件数 N に対して
行数 = ⌊√N⌋、列数 = ⌈N ÷ 行数⌉ で自動計算されます（列数が10を超える場合のみ10列）。
